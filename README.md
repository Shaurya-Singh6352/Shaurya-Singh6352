## 🚀 Featured Projects

### 🔍 ResumeLens

**Java · Spring Boot · Flutter · MySQL · Docker · GitHub Actions · Postman**

A full-stack resume analysis platform that allows users to securely upload resumes and receive structured feedback on content, skills, sections and resume structure.

* 🔐 Built secure RESTful backend services using **Spring Boot, Spring Security, JWT, BCrypt, Spring Data JPA and Hibernate**.
* 📄 Engineered **PDF/DOCX processing with Apache Tika** and developed a rule-based scoring engine for technical skills, sections, contact information, measurable impact and formatting.
* 🐳 Containerized the backend with **Docker** and implemented **GitHub Actions CI/CD** for automated build and deployment.
* 🌐 Deployed the **Flutter frontend on Vercel, Spring Boot backend on Render, and MySQL database on Aiven**.

🔗 **Repositories:** [Backend](https://github.com/Shaurya-Singh6352/resume-analyzer-backend) · [Frontend](https://github.com/Shaurya-Singh6352/resume-analyzer-web)
